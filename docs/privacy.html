Privacy Policy – MovieScout

MovieScout is an open-source application that allows users to discover, search for, and manage lists of movies and TV shows. This application leverages public APIs from TMDB, OMDb, and JustWatch to provide catalog data, ratings, and streaming availability.

Data Collection and Cloud Storage

To synchronize your following titles, pinned titles, and selected platforms across devices, MovieScout stores your app preferences and saved titles in a cloud-hosted Firebase instance.

No personally identifiable information (PII) is collected, stored, or sold. We do not collect your name, email address, location, or contact details.

Third-Party Services

MovieScout uses third-party services to fetch media content and handle cloud storage:

  • The Movie Database (TMDB): Used to retrieve movie/TV metadata, posters, and details.
  • OMDb: Used to retrieve ratings.
  • JustWatch: Used to provide streaming platform availability data.
  • Google Firebase: Used solely to store and sync your watchlist items and app preferences securely in the cloud.

Disclaimers

This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming availability data is provided by JustWatch.

Open Source

MovieScout is fully open source. You can inspect, contribute to, or fork the source code at: GitHub Repository.
